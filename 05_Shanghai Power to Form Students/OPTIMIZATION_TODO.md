# 打浦桥单轮多目标形态优化 TODO

目标工作流：四个情景分别设定约束、主体权限和算子强度 → 各自生成候选方案 → 约束检查 → 三目标评价 → 各自筛选帕累托集合 → 三类利益视角在每个集合内后评价 → 形成 4×3 代表方案 → 三维展示。角色评价不回写优化器。

## 完成标准

- 同一份输入和随机种子产生相同结果。
- 每个候选方案都能追溯到更新单元、算子、参数和受影响建筑。
- 任何被称为“可行”的方案都通过几何、边界、保护、限高、容积率和居住保留检查。
- 三个目标分别输出原始量和归一化值，不用“满意度”“利润”等数据无法支持的名称。
- 居民、开发实施和公共规划三种视角只对帕累托方案排序，不改变本轮优化。
- 所有正式结果保存输入快照、随机种子、代码版本、失败原因和方案文件。

## M3 三个优化目标

- [x] 居住影响暴露：直接修改住宅，加上与增高、拆分或退台建筑位于同一道路围合单元的住宅现状 GFA / 住宅总 GFA；不使用距离权重。
- [x] 正向增建量：满足约束的逐建筑正 GFA 增量 / 研究区面积；内部保留旧字段名以兼容既有导出。
- [x] 净 GFA 变化与正向增建量并列导出和展示，禁止把后者解释成街区总量增加。
- [x] 街道连接的释放地面代理：现状占地减去方案占地后，与道路缓冲相交的面积 / 研究区面积。
- [x] 四情景固定使用 5 m 街道缓冲和同一测量配置。
- [x] 同时保留 FAR、覆盖率、修改建筑数和算子次数等解释指标。
- [x] 用道路围合更新单元作为无权重的间接暴露边界，使只修改开发建筑的情景仍能反映对同单元住宅的形态影响。
- [x] 将正向增建量归一化上限由旧模型的 0.01 校准并冻结为 0.03，高于新增算子预览最大值 0.02377；保留超界复核。
- [x] 冻结本轮第三目标口径为“临街释放地面潜力”；不因背景对象核查而升级为缺乏边界、权属和开放性数据支撑的公共空间效益。
- [ ] 有成本数据后再建立开发可行性或收益指标；此前不使用“利润”。

验收：三个手工构造方案的指标方向符合预期，量纲、分母和零值处理有测试。
