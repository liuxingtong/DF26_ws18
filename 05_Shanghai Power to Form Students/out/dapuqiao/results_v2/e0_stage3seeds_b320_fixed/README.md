# 打浦桥对照实验：现状 + 参数基线 + 三治理情景（5 组）

- 随机种子：11, 23, 37
- 每方法/种子有效独立评价预算：320
- 控制包络：shared（shared = 全研究区统一 36 m / FAR 3.0 / 覆盖率 0.60 / 住宅保留 0.80）
- 体量幅度实验臂：v1（v1 原始幅度（与 2026-10-04 正式对照一致））；参数基线高度倍率 1.00–1.30，足迹保留率 0.75–1.00
- 共同控制基线：36 m、FAR 3.0、覆盖率 0.60、住宅 GFA 保留 0.80；现状超过基线时保留现状下限；共同目标测量使用 5 m 街道缓冲
- 第二目标：净建筑面积变化 =（方案 GFA − 现状 GFA）/ 研究区面积；增建与拆减相互抵消，另存增建、拆减总量
- 第三目标：临街释放地面 / 研究区内 5 m 道路缓冲总面积；只读取建筑足迹与街道网络，不表示面积、权属或可达性
- 现状组（existing_conditions）：三目标均为 0 的参照零点，不参与超体积比较
- 汇总与收敛超体积：四方法全部可行候选合并后统一 min-max，参考点为 (1.1, 1.1, 1.1)；逐运行 run_config.json 的质量值仅为运行时暂定值
- 参数基线是无利益相关者标签的参数对照，不保证在数学上包含治理情景的全部形态
- 排除项分开记录：4 条范围未决历史记录不进入遗产硬约束；32 栋未匹配分区建筑作为不可编辑背景
- 输入模式：已冻结规范研究输入
- 结果性质：论文研究实验，不是法定规划结果

详见 `aggregate_summary.csv`、`existing_conditions.csv`、`baseline_scenario_coverage.csv`、`fairness_audit.csv`、`paired_statistical_tests.csv` 和 `runs/` 下的逐候选 `constraint_log.csv`。
