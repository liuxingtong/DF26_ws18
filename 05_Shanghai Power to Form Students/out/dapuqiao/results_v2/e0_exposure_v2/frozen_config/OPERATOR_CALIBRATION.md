# 算子校准记录

校准使用 `dapuqiao_v1` 研究假设，对38个更新单元分别运行 `densify` 和 `open_ground`，每个算子测试0.25、0.50、0.75和1.00四档强度，共304次独立评价。

## 当前结果

- 304次评价全部通过几何、边界、保护、限高、容积率、覆盖率、住宅保留和新增重叠检查。
- `open_ground` 在所有能产生变化的单元中都随强度单调增加释放地面，没有出现强度更高而效果下降。
- 19 个正式单元没有产生增容效果：`Z04`、`Z06`、`Z08`、`Z09`、`Z10`、`Z17`、`Z18`、`Z19`、`Z22`、`Z23`、`Z24`、`Z26`、`Z27`、`Z28`、`Z30`、`Z33`、`Z34`、`Z35`、`Z36`。原因由逐行校准表区分为无可编辑非保护建筑或无剩余 FAR/限高空间，不再沿用旧草案单元的田子坊整片代理解释。
- `densify` 现在先计算单元允许的总建筑面积，再按各建筑请求增加量的比例统一缩放。达到单元上限后，继续提高强度不会突破 FAR。
- 单个单元的最大增量出现在 `Z31`，约 78,591 平方米。这个结果来自冻结研究控制，不是法定开发容量，后续必须纳入 FAR 参数敏感性分析。
- 单个单元最大的临街释放地面比例约为研究区面积的 0.000473，出现在 `Z31`。

## 当前解释

`densify` 的强度表示对现有建筑高度增量的请求。程序会同时受到逐栋限高和单元剩余 FAR 限制，因此“强度1.0”不保证所有建筑都增加30%，而是表示在允许容量内尽量实现该请求。变更日志中的 `requested_height_m`、`capacity_allocation_ratio`、`zone_available_gfa_m2` 和 `zone_requested_gfa_m2` 可以解释请求如何被截断。

`open_ground` 的强度表示首层轮廓最多缩小至原面积的75%，并在限高允许时通过增高尽量补偿原建筑面积。它目前表示“释放地面潜力”，不能直接称为公共空间。公共空间背景层虽已确认丽园公园身份，但其 OSM 研究多边形、历史面积、历史开放时段与权属都不参与该目标；白玉兰广场继续排除，田子坊入口背景点也不参与计算。

可重复生成完整校准表：

```bash
python scripts/calibrate_dapuqiao_operators.py
```

结果输出到 `out/dapuqiao/calibration/operator_calibration.csv` 和 `operator_calibration_summary.json`。
