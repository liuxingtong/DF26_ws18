# 平台测试操作指引

本次测试约 10 分钟。请比较两种更新情景，各选一个净增建接近 0.2% 的方案，再从中选出你更愿意采用的一个，并用一句话说明理由。没有标准答案，请按自己的理解操作和评分。

使用研究人员提供的页面。本机入口为 [打浦桥平台](http://127.0.0.1:8765/)。测试期间保持默认参数，不点击“Recompute”重新计算。

## 1 先看公共协调

点击 **Step 1 · Choose a scenario**，选择 **Public coordination（公共协调，PC）**。展开 **Scenario details**，看它允许哪些改动。

## 2 看两个角色怎么选

展开 **Step 2 · Choose a perspective**，先点 **Residents（居民）**，再点 **Development（开发）**。观察推荐方案、指标和三维建筑有没有变化；如果两次选中同一方案，也可以继续。

## 3 自己挑一个方案

展开 **Step 3 · Explore Pareto trade-offs**。图中每个点是一个方案：

- 横轴是净增建，右边更多；负值表示总建筑面积减少。
- 纵轴是临街地面释放，上边更多。
- 点的颜色表示居住暴露，具体看图下方色带。

点击横轴最接近 **0.2%** 的方案点，查看指标和三维形态，记下方案编号、净增建、居住暴露和临街释放。不必精确等于 0.2%。若找不到可查看的方案，告诉研究人员。

看三维模型时，拖动旋转，滚轮缩放，右键拖动平移。

## 4 再看开发增长

回到 Step 1，选择 **Development growth（开发增长，DG）**，重复第 2、3 步。记录格式如下：

| 情景 | 方案编号 | 净增建 | 居住暴露 | 临街释放 |
|---|---|---|---|---|
| PC 公共协调 | | | | |
| DG 开发增长 | | | | |

在两个方案中选一个，并补全：“我更愿意采用＿＿，因为＿＿。”如果无法取舍，也可以说明原因。

## 5 填写评价

请按实际体验给以下五句话打分：**1 非常不同意、2 不同意、3 一般、4 同意、5 非常同意**。

1. 我能看懂不同情景允许修改哪些建筑。＿＿分
2. 我能看懂容量、居住暴露与临街释放之间的取舍。＿＿分
3. 我能理解切换角色后方案选择为什么改变。＿＿分
4. 我能通过图表和三维视图比较两个方案。＿＿分
5. 平台帮助我选择方案并说明理由。＿＿分
